# Luminia — Mini Game New Age

Prototype jouable React + Vite.

## Lancer
```bash
npm install
npm run dev
```

Puis ouvre l'adresse affichée par Vite.

## Contrôles
- PC : A/D ou flèches gauche/droite
- Saut : W, flèche haut ou Espace
- Mobile : boutons tactiles
- Atteins le portail bleu pour terminer le niveau.

## Build
```bash
npm run build
```

Le dossier `dist/` peut ensuite être déployé comme site/PWA. Pour une APK, on peut ensuite emballer cette application avec Capacitor.
